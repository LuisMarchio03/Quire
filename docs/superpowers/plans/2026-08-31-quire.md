# Quire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um PWA de leitura instalável onde o dono joga os próprios EPUBs e PDFs, lê com tipografia ajustável e modo foco, e tem destaques, notas e marcas de página sincronizados entre aparelhos.

**Architecture:** Local-first. O arquivo do livro vive só no aparelho, em IndexedDB, atrás da interface `BookStore`. Metadados, capa, progresso e anotações são espelhados no Turso: toda escrita entra numa outbox local e sobe quando há rede, e a leitura puxa deltas por `updated_at` com última-escrita-vence. O `id` do livro é o SHA-256 do arquivo, o que faz o mesmo arquivo reencontrar seu histórico em qualquer aparelho.

**Tech Stack:** React 19, Vite 8, TypeScript 7, Tailwind 4, Vitest 4, `@libsql/client` (Turso), `fflate` (EPUB), `pdfjs-dist` (PDF), `idb`, `vite-plugin-pwa`, funções serverless da Vercel.

**Spec:** `docs/superpowers/specs/2026-08-31-quire-design.md`

import { describe, expect, it, vi } from 'vitest'
import { sha256Hex } from './hash'

describe('sha256Hex', () => {
  it('devolve o hash conhecido de "abc"', async () => {
    const hash = await sha256Hex(new Blob([new TextEncoder().encode('abc')]))
    expect(hash).toBe('ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad')
  })

  it('lê arquivo maior que um bloco e relata progresso crescente', async () => {
    const big = new Blob([new Uint8Array(9 * 1024 * 1024)])
    const fractions: number[] = []
    const hash = await sha256Hex(big, (f) => fractions.push(f))
    expect(hash).toHaveLength(64)
    expect(fractions.at(-1)).toBe(1)
    expect(fractions).toEqual([...fractions].sort((a, b) => a - b))
  })

  it('arquivos com o mesmo conteúdo têm o mesmo hash', async () => {
    const bytes = new Uint8Array([1, 2, 3, 4])
    expect(await sha256Hex(new Blob([bytes]))).toBe(await sha256Hex(new Blob([bytes])))
  })
})
